What AURA does

Text and image analysis running entirely on your own machine

Live Screen Watch

Monitors the window or screen area you choose and reads new text as it appears.

Toxicity Detection

An on-device toxic-bert model scores messages for insults, threats, obscenity and hate.

Harmful Image Guard

An NSFW classifier flags risky visuals, so screenshots and media aren't missed.

Instant Alerts

Audible warnings and on-screen risk levels the moment content crosses the line.

100% On-Device

No cloud, no account, no uploads. Everything is processed locally and discarded.

Tray & Autostart

Runs quietly in the system tray, with optional start-with-Windows protection.

Install in 60 seconds

No Python, no dependencies, nothing else to download

1

Download the installer

Grab AURA_Setup_Windows.exe (v1.0.0) using the button above.

2

Run it

Double-click the file. If SmartScreen warns about an unknown publisher, click More info then Run anyway — the app is unsigned but open source.

3

Pick what to watch

Choose a window or screen region inside AURA. Optionally enable "Start with Windows" for always-on protection.

4

Use it as normal

AURA stays in the tray and alerts you when harmful content shows up. Uninstall anytime from Windows Settings → Apps.

Requirements: Windows 10 or 11 (64-bit), ~4 GB RAM, ~350 MB free disk. Works offline after install.

Privacy by design

AURA never sends your screen, text or images anywhere. All detection models are bundled with the app and run locally on your CPU. Nothing is logged to a server and no account is required.
