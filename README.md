# 0D Technologies Website

Official company website for **0D Technologies** (0th Dimension Technologies) — a software development company building custom applications, billing software, and websites.

## Products

- **[0D Billing](https://0dtechnologies.com/zdt-billing.html)** — A billing/invoicing Android app for small businesses. Create bills, track stock, manage customers.
- **[0D Tailor](https://0dtechnologies.com/zdt-tailor.html)** — A Flutter mobile app for tailors to manage customers, measurements, bills, and deliveries.

## Services

- Custom Application Development
- Custom Software Development
- Website Development
