Company website for **ZDT** — a software development company building custom applications, billing software, and websites.

## Projects

- **[ZDT Billing](https://zdt.com/zdt-billing.html)** — A billing/invoicing Android app for small businesses. Create bills, track stock, manage customers. *Coming soon.*
- **[ZDT Tailor](https://zdt.com/zdt-tailor.html)** — A Flutter mobile app for tailors to manage customers, measurements, bills, and deliveries. *Coming soon.*
